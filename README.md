## Deployment
To deploy this Gatsby project to GitHub Pages:  
1. Ensure repository is correctly configured for GitHub Pages.  
    a. In the GitHub repository, Go to "Settings" > "Pages" > "Build and deployment"  
    b. Under **Source**, ensure "Deploy from a branch" is selected.  
    c. Under **Branch**, select "gh-pages" and the root folder.  
    d. Click Save 
2. Create a Pull Request to merge into the `main` branch.  
3. On merge to `main` will trigger the [Deployment Workflow](.github/workflows/deploy.yml) to download dependencies, build the project, and merge deployment files to the `gh-pages` branch.
